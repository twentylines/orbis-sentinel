Set up recovery access

Ask an Orbis operator with root access to finish the protected recovery setup on this host.

  1. Complete the listener setup and stage the existing Orbis operator with the Sentinel bootstrap.
  2. Prepare and save the emergency key with --bootstrap prepare-key and --bootstrap save-key.
  3. Store the saved key somewhere you can reach while Orbis is offline. Run --bootstrap acknowledge-key and enter the key from that copy when prompted.
  4. Complete the reviewed activation on the host, then check sign-in again here.
Host bootstrap requirements

Use the same protected --bootstrap-operation, --review-sha256 and --plan-sha256 from the host’s setup receipts. For save-key, use --save-key-to with an absolute file path in an existing root-only directory.
